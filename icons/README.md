Return ONLY its existing rounded-square brick-red app icon with the delicate flowing luminous silk-like wave filaments, isolated against a genuinely transparent background. Remove all surrounding cream presentation canvas and remove the 'Shadow Speak' wordmark below. Crop tightly to the rounded-square icon outer bounds, centered and filling the square image with transparent outer corner pixels. Preserve the approved artwork's exact warm terracotta palette, subtle atmospheric shading, thin ivory / pale peach layered translucent wave filaments, organic diagonal crest composition, soft fade, original proportions and rounded corners. Do NOT simplify, redraw as bold lines, add text, add border, add shadows or create any presentation/mockup. The resulting file is a square standalone extension icon asset. Transparency is only outside the rounded square, retain the fully colored tile behind the waves.
